# Weather App 🌤️

A responsive, dynamic weather application built with Vanilla JavaScript, Webpack, and the Visual Crossing Weather API as part of [The Odin Project](https://www.theodinproject.com/) curriculum.

## Features
* **Real-time Weather Data:** Search weather for any location globally.
* **Unit Toggling:** Instant client-side conversion between Fahrenheit (°F) and Celsius (°C).
* **Dynamic Visual Themes:** UI background gradients update dynamically based on current weather conditions (sunny, rainy, cloudy, snowy, etc.).
* **Weather Icons:** Displays high-quality SVG weather icons corresponding to live forecasts.
* **Responsive Design:** Mobile-first, glassmorphism-styled UI optimized for all screen sizes.
* **Loading & Error Handling:** Built-in loading spinner and user feedback for invalid city searches.

---

## Built With
* **JavaScript (ES6 Modules & Async/Await):** Asynchronous API fetching and DOM manipulation.
* **Webpack 5:** Asset bundling, Dev Server, HTML plugin, and CSS loaders.
* **Visual Crossing API:** Weather data source.
* **CSS3:** Custom styles, CSS grid/flexbox, keyframe animations, and glassmorphism styling.
